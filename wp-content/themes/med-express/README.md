# Med Express Delivery WordPress Theme

A premium-quality WordPress theme crafted for Algerian courier, last-mile, and logistics companies. It emphasises conversions with a bold hero, service highlights, process storytelling, testimonials, pricing tables, FAQs, and a contact CTA.

## Key Features

- **Customisable hero and call-to-action** via the WordPress Customizer, including contact details and WhatsApp shortcut.
- **Responsive design** with polished typography, gradients, and cards optimised for desktop and mobile.
- **Homepage sections** for services, industries, process timeline, testimonials, pricing, FAQs, blog highlights, and contact form.
- **Widget-ready footer** with three columns plus dedicated footer navigation.
- **Dashicons-powered iconography** and Google Fonts (`Outfit` and `Poppins`).
- **Translation-ready** string usage with the `med-express` text domain.
- **Custom logo support** and accessible navigation with keyboard-friendly menu toggle.

## Installation

1. Copy the `med-express` directory to your WordPress installation under `wp-content/themes/`.
2. In the WordPress admin, go to **Appearance → Themes** and activate “Med Express Delivery”.
3. Configure menus, widgets, and homepage content as desired. Set a static front page using the included template for the full landing experience.
4. Visit **Appearance → Customise** to update hero messaging, CTA, and contact information.

## Recommended Plugins

- **Contact Form 7** or **WPForms** for a functional contact form (replace the placeholder form markup on the homepage).
- **Yoast SEO** or **Rank Math** for SEO enhancements.

## Development Notes

- Primary stylesheet is located at `assets/css/main.css` and loaded via `style.css`.
- JavaScript enhancements reside in `assets/js/navigation.js` and `assets/js/theme.js`.
- Customizer options are declared in `inc/customizer.php` and helper template tags in `inc/template-tags.php`.

Feel free to adapt branding colours and imagery to match the latest Med Express assets.
